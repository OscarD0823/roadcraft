# RoadCraft Studio 0.9.4 · Actualizaciones opcionales

- Nuevo botón **Actualizaciones** (↻) en la cabecera.
- Muestra la versión instalada; **Buscar actualizaciones** consulta solo los datos de la última publicación estable del repositorio propio.
- **Descargar instalador** abre el archivo publicado en GitHub en el navegador. No lo ejecuta ni instala.
- **Seguir con esta versión**, cerrar o Escape permiten continuar sin actualizar, incluso durante una consulta.
- Sin comprobaciones programadas ni descargas en segundo plano. Los errores de conexión no bloquean el editor.
- Consultar o abrir una actualización no limpia archivos del juego, imágenes o copias, ni cierra o reinicia la aplicación.
- Panel adaptable, controles por teclado, respuestas atrasadas descartadas y validación del repositorio, etiqueta y nombre del instalador.

Antes de ejecutar un instalador descargado, guarda tus cambios y cierra el editor. Se mantiene la distribución exclusiva de GitHub y la cabecera compacta de 0.9.3.
