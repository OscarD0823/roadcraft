# RoadCraft Studio 0.9.0

- Nueva consola de reconstrucción inspirada en la distribución de Caja Fantasma, con biblioteca lateral y paneles oscuros.
- Identidad de RoadCraft: recuperar, transformar el terreno y conectar rutas logísticas. La secuencia de maquinaria es una ilustración, no progreso real de misiones.
- Visor siempre junto a ajustes por categorías, navegación adaptada a pantalla dividida y foco de teclado visible.
- Se conservan convoyes A → B, variantes vinculadas, arena, modelos/pintura locales, partidas y copias.
- Carreteras libres sigue siendo experimental, desactivado por defecto y no comprobado en una partida real. Restaurar reglas no deshace terreno guardado.
- Actualizar o abrir el editor no modifica paquetes ni partidas. No se incluyen recursos propietarios del juego.

Referencia conceptual: https://www.focus-entmt.com/en/games/roadcraft
